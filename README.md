# alymagassouba.com

Personal website of Aly Magassouba, served by GitHub Pages at https://www.alymagassouba.com.

The pages are plain HTML generated by `build.py` from `templates/base.html` and the page
bodies in `content/`. The publication lists are generated from the CV's bibliography
(`../CV/publications.bib`), and `cv.pdf` is copied from `../CV/cv_public.pdf`, so the CV and
the website always list the same publications.

## Update

1. Edit `content/*.html`, or add a publication to `../CV/publications.bib`.
2. Rebuild the public CV in `../CV` if it changed.
3. Run `python build.py`, check the pages locally, then commit and push.
